# Инструкция по установке и запуску виджета Claude (Claude Usage Overlay)

Этот виджет позволяет отслеживать затраты токенов в Claude Code прямо на вашем экране поверх всех окон.

## Предварительные требования
Для работы виджета на вашем компьютере должен быть установлен **Node.js** (скачать можно с официального сайта: https://nodejs.org).

## Быстрый старт (для пользователей)

Мы подготовили три удобных скрипта (батника) для быстрой работы:

### 1. Установка `1_install.bat`
Запустите этот файл первым. Он автоматически скачает и установит все необходимые библиотеки (зависимости) для работы интерфейса (через команду `npm install`). 
*Дождитесь сообщения "Готово" или "Успешно установлено", прежде чем переходить к следующим шагам.*

### 2. Настройка автозапуска (по желанию) `2_autostart.bat`
Если вы хотите, чтобы виджет запускался сам каждый раз при включении компьютера, запустите этот файл. Он аккуратно создаст ярлык программы в системной папке автозагрузки Windows.
*(Отключить автозапуск всегда можно будет вручную через диспетчер задач Windows).*

### 3. Запуск виджета `3_start.bat`
Запустите этот файл, чтобы включить виджет прямо сейчас. Он появится в правом верхнем углу экрана поверх всех окон. 
*(Вы также можете скрыть или показать виджет комбинацией клавиш `Ctrl + Shift + U` или через оранжевую иконку в системном трее рядом с часами).*

---

## Как это работает под капотом
Виджет автоматически читает логи использования Claude, которые сохраняются в папке `.claude` вашего компьютера (в том числе подтягивает логи из WSL Ubuntu, если вы пользуетесь им). 
Все графики и расчеты стоимости в рублях/долларах будут обновляться в режиме реального времени.
