# Установка Claude Usage Overlay

Виджет always-on-top для мониторинга лимитов Claude Code. Работает на Windows.

## Что нужно заранее

- **Windows 10/11**
- **Node.js 18+** (вместе с ним ставится `npm`) — https://nodejs.org
- Установленный и хотя бы раз запущенный **Claude Code** — виджет читает его логи из
  `%USERPROFILE%\.claude\projects\**\*.jsonl`. Без этих логов показывать будет нечего.

Проверить, что Node стоит:

```powershell
node -v
npm -v
```

## Шаг 1. Положить проект и установить зависимости

Скопируй папку проекта куда удобно (например `C:\Tools\claude-widget`).
Путь может быть любым — скрипты не захардкожены. Затем:

```powershell
cd C:\Tools\claude-widget
npm install
```

## Шаг 2. Проверить, что запускается

```powershell
npm start
```

Должно появиться маленькое окно поверх всех окон и оранжевая иконка в трее.

- **Ctrl+Shift+U** — показать/скрыть окно
- Правый клик по иконке в трее → Show/Hide / Reload / Quit

Если окно пустое или нули — значит Claude Code ещё не успел записать логи. Поработай в нём,
нажми в виджете «Reload data».

## Шаг 3. Включить автозапуск при входе в Windows

```powershell
npm run autostart:install
```

Это создаёт ярлык в папке автозагрузки Windows
(`%APPDATA%\Microsoft\Windows\Start Menu\Programs\Startup\Claude Widget.lnk`),
который при логине запускает виджет **скрыто, без мелькающего окна консоли**
(через `start-widget.vbs` → `wscript.exe`).

Отключить автозапуск:

```powershell
npm run autostart:uninstall
```

## Шаг 4. (Важно) Подогнать лимиты под свой тариф

По умолчанию лимиты выставлены под **Max 5×**. Если тариф другой — поправь объект `LIMITS`
в начале `main.js`:

```js
const LIMITS = {
  session5h:    88,     // $ за 5-часовое окно
  weeklyAll:    2400,   // $ в неделю (все модели)
  weeklySonnet: 1800,   // $ в неделю (только Sonnet)
};
```

Ориентиры для других тарифов (примерно):

```js
// Max 20×
const LIMITS = { session5h: 352, weeklyAll: 9600, weeklySonnet: 7200 };

// Pro
const LIMITS = { session5h: 8.8, weeklyAll: 240, weeklySonnet: 180 };
```

Точнее всего проценты 5h и 7d виджет берёт не из расчёта, а с сервера — если настроен
хук `statusLine` (см. `CLAUDE.md`, раздел про `statusline-writer.js`). Это опционально;
без него проценты считаются из логов и расходятся с личным кабинетом на ~7–8%.

## Возможные грабли

- **Виджет не стартует после перезагрузки** — проверь, что папка проекта доступна на момент
  входа в систему (особенно если она на внешнем/сетевом диске). Ярлык указывает на конкретный
  путь — если папку переместишь, переустанови автозапуск: `npm run autostart:uninstall`,
  потом `npm run autostart:install` из нового места.
- **`npm` не находится** — Node.js не установлен или не в `PATH`. Переустанови Node, открой
  новый терминал.
- **Две иконки в трее** — не должно случаться (есть single-instance lock), но если запускал
  вручную при уже работающем автозапуске — просто Quit лишний.
